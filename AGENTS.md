## Go development

For Go coding, review, debugging, or setup, load the `golang-how-to` skill and relevant secondary skills. Keep service packages independent of the root package; common HTTP behavior belongs in internal/transport.

## CodeGraph

If a `.codegraph/` directory exists, use `codegraph_explore` or `codegraph explore` before searching or reading code to understand symbols. Otherwise skip CodeGraph; do not create an index without a user request.
